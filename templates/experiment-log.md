# 实践记录模板

复制本文件，以 `YYYY-MM-DD-主题.md` 保存。空白项没有材料时保留，不替自己补经历。

- 日期与负责人：
- 状态：计划 / 进行中 / 已完成 / 已停止。
- 材料性质：本人实践 / 公开资料研究 / 演示示例。

## 原始问题

谁遇到了什么具体问题？为什么值得解决？

## 实验前的判断

我原先怎么想？哪些只是待验证的假设？

## 怎么做的

步骤、时间、成本、工具与版本、样本、对照方式。

## 证据与结果

| 指标或观察 | 基线 | 本次结果 | 周期与样本 | 原始证据 | 证据性质 |
| --- | --- | --- | --- | --- | --- |
| | | | | | 实测 / 来源自述 / 推测 / 示例 |

## 判断怎样改变

支持什么、推翻什么、还不能说明什么？结论适用的条件是什么？

## 别人怎样复用

能交付的文件或工具、适用条件、限制、复现步骤。

## 下一步

继续 / 修改 / 停止。只写一个下一步验证动作。

## 来源与修订

来源链接、访问日期、版本，后来修正过什么。
